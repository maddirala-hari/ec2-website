# DevOps Lab – GitHub and EC2 Deployment

## Project Overview
This project is a basic HTML website created to practise GitHub source code management and AWS EC2 deployment.

## Technologies Used
- HTML
- Git and GitHub
- AWS EC2

## Implementation Steps
1. Created an HTML website.
2. Stored the source code in a GitHub repository.
3. Practised Git operations such as commits, branches, and pull requests.
4. Used the project to practise deploying a website on an EC2 instance.

## Learning Objectives
- Understand GitHub repository management.
- Practise version control and collaboration workflows.
- Learn the basic process of deploying a website on AWS EC2.

## Project Status
Basic practice project for DevOps learning.
